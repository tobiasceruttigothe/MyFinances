Sistema de diseño · v1

El cuaderno, traducido a código.

Este documento es el manual del sistema visual de MyFinances. Tokens, tipografía, componentes con código TypeScript copiable, patrones recurrentes y un mapa para migrar lo que ya existe en frontend/src/. Todo lo que ves abajo está construido con los mismos tokens que tendrías que copiar en frontend/src/index.css.

Fundación · sombras

Dos sombras, nada más.

Usamos sombras con moderación. Una sombra suave para tarjetas elevadas, una más fuerte para overlays y modales. Tono cálido (tinta diluida), nunca gris frío.

Componente

Button.

Tres variantes: ink (primario, sólido, pill), outline (secundario, borde fino, radio 6px) y ghost (terciario, serif italic, sin fondo). Reservar danger para acciones destructivas. 

// frontend/src/components/ui/button.tsx
import type { ButtonHTMLAttributes } from 'react';
import { cn } from '@/lib/utils';

type Variant = 'ink' | 'outline' | 'ghost' | 'danger';

interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: Variant;
  icon?: React.ReactNode;
}

export function Button({ variant = 'ink', icon, children, className, ...rest }: ButtonProps) {
  return (
    <button
      className={cn(
        'inline-flex items-center gap-2 font-sans font-semibold text-[13.5px] leading-none cursor-pointer',
        variant === 'ink'     && 'bg-ink text-paper px-[18px] py-[11px] rounded-full',
        variant === 'outline' && 'border border-rule px-[18px] py-[11px] rounded-md text-ink',
        variant === 'ghost'   && 'text-sepia font-serif italic px-[18px] py-[11px]',
        variant === 'danger'  && 'bg-wine text-paper px-[18px] py-[11px] rounded-full',
        className,
      )}
      {...rest}
    >
      {icon}
      {children}
    </button>
  );
}
Componente

Input.

En vez del input "caja" típico, usamos una línea inferior — como una línea de cuaderno. La línea es fina por default y se vuelve tinta sólida cuando el campo está focuseado o lleno.

Importe
// frontend/src/components/ui/input.tsx
import type { InputHTMLAttributes } from 'react';
import { cn } from '@/lib/utils';

interface InputProps extends InputHTMLAttributes<HTMLInputElement> {
  label?: string;
}

export function Input({ label, className, ...rest }: InputProps) {
  return (
    <div>
      {label && (
        <div className="text-[10.5px] uppercase tracking-[0.14em] text-sepia font-semibold mb-1.5">
          {label}
        </div>
      )}
      <input
        className={cn(
          'w-full font-serif text-[17px] bg-transparent outline-none px-0 py-1.5',
          'border-b border-rule focus:border-ink transition-colors',
          'placeholder:text-sepia placeholder:italic',
          className,
        )}
        {...rest}
      />
    </div>
  );
}

Tokens en CSS.

Copiá este bloque entero como reemplazo del que está hoy en frontend/src/index.css. Compatible con Tailwind v4 a través de @theme. 

/* frontend/src/index.css */
@import "tailwindcss";

@theme {
  /* Cuaderno · paleta papel */

  --color-paper-2:    #ede2cd;
  --color-ink:        #1a1612;
  --color-rule:       #c9bca0;
  --color-sepia:      #7c5a2a;
  --color-sage:       #5e7a4f;
  --color-wine:       #9a3a2e;
  --color-gold:       #d4a657;

  /* Cuaderno · paleta tinta (inversiones) */
  --color-tinta-bg:    #1f2a38;
  --color-tinta-bg-2:  #27374a;
  --color-tinta-rule:  #36465a;
  --color-tinta-ink:   #ecdfbd;
  --color-tinta-sepia: #c7a974;
  --color-tinta-sage:  #9ec79c;
  --color-tinta-wine:  #d27e7e;
  --color-tinta-gold:  #d4a85a;

  /* Fuentes */
  --font-serif: 'Newsreader', Georgia, serif;
  --font-sans:  'Hanken Grotesk', system-ui, sans-serif;
  --font-mono:  'JetBrains Mono', ui-monospace, monospace;

  /* Radios */
  --radius-xs: 4px;
  --radius-sm: 6px;
  --radius-md: 8px;
  --radius-lg: 12px;

@layer base {
  body {
    background: var(--color-paper);
    color: var(--color-ink);

      radial-gradient(circle at 90% 100%, rgba(196,170,120,0.16), transparent 50%);
    background-attachment: fixed;
  }
}

Migración del repo actual.

Lo que ya existe en frontend/src/ y cómo corresponderlo a este sistema. Ordenado por prioridad.

Archivo actual Acción Notas
src/index.css → reemplazar completo Borrar los tokens HSL shadcn. Pegar el bloque de @theme de arriba. Los .dark selectors no se usan acá (la app es light por default; "tinta" es una sección, no un modo).
components/ui/button.tsx → reescribir con variants Quitar cva + class-variance-authority y usar el patrón de arriba. Variantes: ink · outline · ghost · danger.
components/ui/card.tsx → reescribir como PaperCard Sin CardHeader/Content/Footer separados; el contenido fluye libre. Solo un wrapper con borde sepia y bg paper/40.
components/ui/input.tsx → reemplazar con línea Sacar el border completo. Usar solo border-bottom, font-serif para el valor, label uppercase encima.
components/ui/label.tsx → embeber en Input El componente Input ya recibe label?: string y lo renderiza. Eliminar el componente Label suelto.
components/ui/badge.tsx → reescribir Variants: sepia (default) · sage · wine · ink. Siempre pill, padding 4×10.
components/ui/toast.tsx → rehacer estilo "papel" Aparece como una tira de papel desde abajo a la derecha. Sage para éxito, wine para error. Cita italic en serif.
components/ui/skeleton.tsx → mantener, ajustar color Cambiar el shimmer gris por var(--sepia-soft). Misma idea.
components/shared/AppLayout.tsx → rehacer sidebar Quitar el azul. Sidebar de papel con borde sepia derecha, items en serif. Item activo: bg ink, texto paper, italic con ❧.
features/dashboard/DashboardPage.tsx → aplicar layout nuevo Reemplazar los SummaryCards con la stat-row de 3 celdas. Pie chart → barras horizontales por categoría. Cards azules con gradiente → PaperCard simple.
features/investments/InvestmentsPage.tsx → aplicar paleta Tinta Toda esta página corre con los tokens --color-tinta-*. Wrapper con data-mode="tinta" para hacer el switch a nivel de página.
recharts (Pie, Line) → simplificar paleta Reemplazar el array COLORS azul/verde/violeta por: [sepia, sage, wine, gold, ink60, sepia60].
tailwind shadcn defaults → remover Las variables --background --foreground --primary --primary-foreground etc. del bloque @layer base :root ya no se usan. El sistema arranca de los tokens nuevos.

Orden sugerido de migración

  1. Reemplazar src/index.css con los tokens nuevos. Cargar las tres fuentes en index.html.
  2. Reescribir Button, Input, Card, Badge. Como toda la app los usa, una vez listos cambia el look del producto entero sin tocar las páginas.
  3. Rehacer AppLayout (sidebar) — el chrome que envuelve todo.
  4. Migrar página por página: Dashboard, Transacciones, Reportes, Metas, Categorías. Cada una toma ~30-60 min siguiendo los patrones documentados acá.
  5. Inversiones al final, con el switch a la paleta Tinta. Es la que tiene más diferencias, conviene hacerla con el resto ya estabilizado.
  6. Auth (Login/Register) y Profile — pueden ir antes o después, son independientes.
Una decisión pendiente: hoy recharts está instalado para el pie + line del dashboard y reports. Es robusto pero "pesado" para los micro-gráficos. Para sparklines (inversiones) recomiendo SVG inline puro — ya lo prototipamos así y queda mejor con menos código. Para el line chart de Reportes seguir con recharts está perfecto.
